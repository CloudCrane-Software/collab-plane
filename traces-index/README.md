# traces-index/ · 轨迹与大产物索引

> 原文私存（srv-1 受控存储/MinIO，裁决 R4），本目录只放 **≤2KB 索引 + SHA-256**。

## 索引条目格式

```text
- <名称> | <日期> | <类型：trace|job|report|artifact> | sha256:<hex> | <受控存储路径代号或说明≤64字>
```

## 规则

1. 单条 ≤2KB；超限拆条或只留 hash。
2. SHA-256 必填：与受控存储原件核对一致方可登记（哈希比对命令输出全等）。
3. 禁止粘贴轨迹正文、任务卡 context、任何密钥形状（CI 泄密扫描会拦）。
4. holdout 用例只登记 id + SHA-256，永不登记内容。
