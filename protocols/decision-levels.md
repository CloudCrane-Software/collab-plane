# 决策分级（L0-L3）

> 版本：v0.1.0-draft（2026-10-03，自 local-plane PROTOCOL §7 升格；沿用体系既有协议）

| 级别 | 含义 | 流程 |
|---|---|---|
| L0 | 自决：不影响他人、可逆（改自己任务文件、跑只读探测） | 直接做，journal 留痕 |
| L1 | 默认通过（24h 静默期）：常规建设动作、新任务排期 | planner 可批 |
| L2 | 表决（48h）：影响多角色/需协调（协议修订、任务打回重做） | 相关角色表决 + journal 留痕 |
| L3 | 升级 owner：不可逆且影响全体；要新凭据/预算/权限；"要不要做"的价值判断 | owner 裁定；**"怎么做"一律不升 L3** |

- 契约（protocols/）冻结后的任何改动 = 高影响决策路径：5 强 ensemble 评审 + 1 强合成 + decision_record（见 protocols/README.md 冻结纪律）。
- owner 偏好：给选择题（推荐项+理由），不给填空题。
